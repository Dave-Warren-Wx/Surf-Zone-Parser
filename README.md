Surf Forecast Parser

This Python script retrieves and parses NOAA surf zone forecasts for South Florida.

It extracts the forecast information needed for broadcast and weather graphics use and outputs the results as structured CSV data.

Features
Automatically identifies the appropriate forecast period
Extracts:
Surf height
Surf conditions
Water temperature
Rip current risk
Other relevant surf forecast information
Converts forecast text into structured data
Outputs data as a CSV
